# تقرير المرحلة 2 — Android والتابلت والوظائف المشتركة

## ما تم إنجازه
1. **إدخال صور الشارت** (مشترك بين كل الأجهزة):
   - نقطة نهاية `/analysis/inputs` تستقبل صورة من رفع ملف أو المشاركة أو لقطة شاشة، تتحقق أنها صورة حقيقية بفك ترميزها بـ OpenCV، تقرأ أبعادها الفعلية، تحفظها PNG محلياً، وتربطها بالجلسة الجارية.
   - النتيجة **صادقة**: WAIT مع "محرك قراءة الشارت غير مثبت بعد" و"التحليل مبني على الصورة فقط"، ولا تُسجَّل إشارة وهمية في الإحصاءات.
   - لقطات الشاشة الآلية تتطلب إذن قراءة الشاشة؛ المشاركة والرفع فعل يدوي من المستخدم فلا تتطلبه. مرفوضة أثناء الإيقاف الفوري.
   - حد احتفاظ (آخر 500)، حذف آمن، وشمول في النسخ الاحتياطي والحذف الشامل.
   - ترحيل قاعدة البيانات إلى الإصدار 2 مع ترقية قواعد المرحلة 1 دون فقد بيانات.
2. **المحرك المضمّن لـ Android**: `uata/android_entry.py` يشغّل نفس المحرك في خيط داخل التطبيق؛ `MainActivity.kt` يبدأ Python (Chaquopy 17.2) عبر قناة `uata/engine` ويحفظ البيانات في التخزين الخاص بالتطبيق.
3. **طبقة اتصال موحدة** `EngineHost`: محرك منفصل (Windows) أو مضمّن (Android) بنفس `EngineApi`.
4. **النافذة العائمة على Android**: زر في اللوحة يطلب إذن "الظهور فوق التطبيقات" صراحةً، ثم يعرض بطاقة قابلة للسحب تعرض الإشارة والثقة والمدة والإطار والحالة وتتحدث تلقائياً. **عرض فقط** — لا تتفاعل مع التطبيقات الأخرى.
5. **استقبال المشاركة**: لقطة شارت من أي تطبيق ← "مشاركة" ← UATA ← نتيجة التحليل. ملفات PDF/Word/Excel/نصوص/فيديو ← المكتبة بانتظار الموافقة. أنواع غير مدعومة أو مكررة يُبلَّغ عنها.
6. **زر "تحليل صورة شارت"** في اللوحة (يعمل على Windows وAndroid).
7. **تخطيط متكيف**: هاتف = اللوحة كاملة؛ تابلت عمودي = شريط تنقل جانبي؛ تابلت أفقي (≥1000) = اللوحة مثبتة بجانب الشاشة المختارة.
8. **أمان Android**: HTTP غير مشفر مسموح لـ `127.0.0.1` فقط، `allowBackup=false` (لا نسخ سحابي تلقائي لبياناتك)، كل الأذونات بطلب صريح.
9. **CI**: وظيفة جديدة تبني APK وترفعه كـ artifact.

## الأخطاء التي عولجت
* اختبار المكتبة بعرض 1000 أصبح يدخل تخطيط التابلت (المكتبة أضيق) ⇒ اختبار التخطيط العريض بعرض 1500 وإضافة اختبارات مخصصة لكل تخطيط.
* عند فشل تشغيل المحرك المضمّن كان التطبيق سيحاول مسار سطح المكتب ⇒ يُعرض الآن "غير متصل" مع السبب.

## ما لم يُتحقق منه (بصراحة)
* **لم يُبنَ APK ولم يُختبر على جهاز Android.** بيئة التطوير هنا لا تصل إلى `dl.google.com` (Android SDK) و`chaquo.com` (حزم Python لأندرويد)، ورُفض توسيع صلاحيات الشبكة. الكود الأصلي (Kotlin/Gradle/Manifest) مكتوب لكنه **غير مُترجم بعد**. وظيفة CI الجديدة ستبنيه — بشرط إصلاح صلاحية الرفع إلى GitHub.
* **مخاطرة معروفة**: توافر `pydantic-core` و`cryptography` بإصدارات Chaquopy، وتوافق Chaquopy 17.2 مع Android Gradle Plugin 9.3. إن فشل البناء في CI فسيكون هنا أولاً، والحل البديل تثبيت إصدارات أقدم أو استبدال الاعتمادية.
* **الالتقاط المستمر للشاشة** (MediaProjection) مؤجل إلى المرحلة 3 مع قراءة الشارت؛ المتاح الآن هو المسار الذي تسمح به المواصفات صراحةً: المشاركة.
* **iOS**: التطبيق المرافق (Share Extension) يحتاج Xcode/macOS — لم يُنفذ. كود Dart الخاص بالمشاركة يدعم iOS، لكن تشغيل المحرك على iOS يحتاج قراراً معمارياً (محرك مضمّن أو اقتران بمحرك الكمبيوتر).
