# تصميم واجهة المستخدم

## اللوحة العائمة (الوضع المضغوط ~340×520)
```
┌──────────────────────────────────────┐
│ ● مساعد التداول الذكي          —  ✕ │  ← شريط سحب (DragToMoveArea)، نقطة الحالة
├──────────────────────────────────────┤
│ ┌───────────────┐ ┌───────────────┐  │
│ │  ↗ شراء BUY   │ │  ↘ بيع SELL   │  │  ← أخضر / أحمر، المضيء = التوصية الحالية
│ └───────────────┘ └───────────────┘  │
│ ┌──────────────────────────────────┐ │
│ │        ⌛ انتظار WAIT             │ │  ← كهرماني
│ └──────────────────────────────────┘ │
│  الثقة التقديرية │ مدة الصفقة │ الإطار │
│   — (غير معايرة) │     —      │  30ث   │
│        التحليل متوقف                 │  ← حالة السوق/المحرك + السبب
│ [▶ بدء التحليل]      [■ إيقاف]       │
│ [⏻ إيقاف فوري ...................]   │  ← أحمر، متاح دائماً عند الاتصال
│  📚 المكتبة  🎓 التدريب  🧾 السجل  ⚙  │
│  التنفيذ يدوي بالكامل — لا تنفيذ صفقات │
└──────────────────────────────────────┘
```

* **النقر على BUY/SELL/WAIT** يفتح "تفاصيل الإشارة": النوع، الأسباب، العوامل المؤيدة والمعارضة، جودة البيانات، الثقة (مع وسم "غير معايرة")، المدة، الاستراتيجية، أساس التحليل. لا ينفذ أي شيء.
* **النافذة**: بلا إطار، فوق التطبيقات (قابل للإلغاء)، قابلة للسحب وتغيير الحجم (حد أدنى 300×420)، شفافية قابلة للتعديل، تتذكر موضعها وحجمها. تُستخدم واجهات نظام التشغيل فقط — لا حقن في صفحات المنصات.
* **فتح شاشة** (المكتبة، السجل…) يكبّر النافذة إلى 1000×720 ويعيدها لحجمها وموضعها عند الرجوع.
* **غير متصل بالمحرك**: الأزرار معطلة، رسالة "المحرك المحلي غير متصل" مع تعليمات التشغيل وزر إعادة المحاولة.

## الشاشات
| الشاشة | الوظائف العاملة في المرحلة 1 |
|---|---|
| المكتبة | إضافة ملاحظة (نوع: ملاحظة/قاعدة/جزء استراتيجية/مثال/تعريف + تصنيف + وسوم)، رفع ملف (PDF/DOCX/XLSX/TXT/صور/فيديو)، إضافة رابط، بحث نصي، تفاصيل المصدر (النوع، التاريخ، الحجم، حالة الاستخراج)، اعتماد/رفض كل عنصر، حذف. تخطيط قائمة + تفاصيل على الشاشات العريضة (تابلت/كمبيوتر). |
| السجل | تبويب الإشارات (عدادات BUY/SELL/WAIT + فتح التفاصيل)، تبويب النتائج (تسجيل نتيجة، بطاقات منفصلة لمحاكاة/تجريبي/حقيقي مع حجم العينة وتحذير العينة الصغيرة، حذف). |
| التدريب | يعرض الحالة الفعلية لمكونات المحرك كما يبلغ عنها (لا واجهة وهمية). يُبنى في المرحلة 7. |
| الإعدادات | كل الإعدادات: إطار الشمعة (مع تحذير مصدر بيانات 30ث)، مدد الصفقة، منع التكرار، أقل عدد عوامل، أدنى ثقة وجودة، التحليل المستمر، تفعيل/تعطيل 15 عاملاً، اللغة، المظهر، فوق التطبيقات، الشفافية، إذن قراءة الشاشة (بتأكيد)، المصادر الخارجية، النسخ المشفر والاستعادة، استعادة الافتراضي، حذف كل البيانات. |

## اللغة والاتجاه والمظهر
* العربية افتراضياً (RTL) والإنجليزية (LTR)، التبديل فوري. النصوص في `app/lib/l10n/strings.dart`.
* داكن / فاتح / حسب النظام.
* الألوان الدلالية ثابتة في الوضعين: BUY `#16A34A`، SELL `#DC2626`، WAIT `#F59E0B`، مع أيقونة ونص (لا اعتماد على اللون وحده).
