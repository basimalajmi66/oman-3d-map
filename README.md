# Universal AI Trading Assistant — مساعد التداول الذكي

مساعد تداول مستقل عن أي منصة، يعمل محلياً، يتعلم مما تعلّمه إياه بعد موافقتك، ويعرض توصيات **BUY / SELL / WAIT** مع أسبابها.
**لا ينفذ أي صفقة إطلاقاً — القرار والتنفيذ بيدك.**

> الحالة: **المراحل العشر منفذة**؛ المراحل **1 و3 و4 و5 و7 و8 و9 و10 مكتملة**، و**6** عدا تحويل الكلام إلى نص (ملفات الترجمة مدعومة)، و**2**: Android/التابلت **تطبيق مرافق** يستخدم محرك الكمبيوتر عبر الشبكة المحلية (اقتران QR، اتصال مشفّر). نسخة Windows تُبنى كمثبّت ويُختبر تثبيتها فعلياً في CI. **الإشارات BUY/SELL تصدر فقط من استراتيجية اعتمدتها بعد اختبار خارج العينة على بيانات حقيقية؛ وإلا WAIT مع السبب.**
> محرك التحليل (قراءة الشارت، المؤشرات، الإشارات) يُبنى في المراحل 3–8؛ حتى ذلك الحين تعرض الأداة **WAIT** وتوضح السبب بدل أي إشارة مختلقة.

## الهيكل
```
backend/            المحرك المحلي (Python + FastAPI + SQLite)
  uata/api/         واجهة HTTP على 127.0.0.1 بتوكن
  uata/services/    الإعدادات، التحكم، المعرفة، السجلات، النسخ الاحتياطي
  uata/db/          الاتصال والترحيلات + schema_v1.sql
  uata/vision/       قارئ الشارت (OpenCV + Tesseract)
  uata/analysis/     التحليل الفني (مؤشرات، أنماط، هيكل السوق)
  uata/knowledge/    استخراج المستندات، القواعد، التعارضات، الاسترجاع الهجين
  uata/video/        تحليل الفيديو التعليمي
  uata/strategy/     الاستراتيجيات والاختبار التاريخي
  uata/signal/       محرك القرار
  tests/            201 اختبار pytest
  bench/            قياس الأداء
app/                تطبيق Flutter (Windows / Android / iOS)
  lib/core/         عقد المحرك، عميل HTTP، تشغيل المحرك، التحكم بالنافذة
  lib/state/        حالة التطبيق
  lib/ui/           اللوحة العائمة والشاشات
  lib/l10n/         العربية والإنجليزية
  test/             اختبارات الواجهة + اختبارات العقد مع المحرك الحقيقي
docs/               المعمارية، قاعدة البيانات، تصميم الواجهة، خطة الاختبار، التقارير
scripts/            بناء Windows وتشغيل المحرك للتطوير
```

## متطلب اختياري: OCR
لقراءة الأسعار من محور الشارت ثبّت [Tesseract](https://github.com/UB-Mannheim/tesseract/wiki) (Windows) أو `apt install tesseract-ocr`. بدونه يعمل القارئ بقيم نسبية ويوضح ذلك.

## التشغيل للتطوير
```bash
# 1) المحرك
cd backend
pip install -r requirements-dev.txt
python -m uata                 # يستمع على 127.0.0.1:8765 ، البيانات في %LOCALAPPDATA%\UniversalAITradingAssistant
python -m pytest               # الاختبارات

# 2) الواجهة (Windows)
cd app
flutter pub get
flutter run -d windows         # أو اضبط UATA_BACKEND_DIR ليشغّل التطبيق المحرك بنفسه
flutter test
```

## الهاتف والتابلت (تطبيق مرافق)
```bash
cd app && flutter build apk --debug      # لا يحتوي Python: المحرك على الكمبيوتر
```
1. على الكمبيوتر: الإعدادات ← **الأجهزة المرافقة** ← فعّل «السماح لهاتفي باستخدام هذا الكمبيوتر» (معطّل افتراضياً). سيطلب Windows إذن الجدار الناري للشبكة الخاصة.
2. اضغط «اقتران جهاز جديد» فيظهر رمز QR صالح **لمرة واحدة ولمدة 5 دقائق**.
3. على الهاتف: افتح التطبيق وامسح الرمز (أو الصق الرابط).

* الاتصال **TLS** بشهادة مولّدة على كمبيوترك؛ الهاتف يتحقق من بصمتها الواردة في الرمز، فلا يمكن لأحد على الشبكة قراءة الاتصال أو انتحال الكمبيوتر.
* لكل جهاز رمز خاص يُخزّن على الكمبيوتر كبصمة فقط، ويمكن إلغاؤه فوراً من نفس القسم.
* من الهاتف: متابعة التحليل والتوصية، إرسال الشارت والملفات (تنتظر موافقتك)، تسجيل النتائج، الإحصاءات، **زر الإيقاف الفوري**.
* **غير مسموح من الهاتف أبداً**: حذف البيانات، النسخ الاحتياطي، تغيير الإعدادات، التقاط شاشة الكمبيوتر، إدارة الأجهزة.
* «حذف كل البيانات» يلغي كل الأجهزة ويولّد شهادة جديدة.

## بناء نسخة Windows كاملة
```powershell
./scripts/build_windows.ps1                                  # مجلد Release فقط
./scripts/build_windows.ps1 -BundleTesseract -Installer      # + Tesseract (عربي/إنجليزي) + مثبّت Inno Setup
# الناتج: dist\UATA-Setup-<version>.exe  (~170MB، يتضمن المحرك وTesseract وFFmpeg)
```
* المثبّت للمستخدم الحالي (`%LOCALAPPDATA%\Programs\UATA`) ولا يحتاج صلاحيات مسؤول، ويضيف اختصاراً في قائمة ابدأ.
* إلغاء التثبيت يوقف المحرك ويحذف البرنامج، **ويُبقي بياناتك** (قاعدة البيانات والنسخ) — احذفها من الإعدادات ← حذف كل البيانات إن أردت.
* يبني CI المثبّت على `windows-latest`، **يثبّته بصمت، يشغّل المحرك من مجلد التثبيت ويتحقق أن OCR بالعربية وFFmpeg يعملان، ثم يلغي التثبيت**، ويرفع `uata-windows-installer`.
* ما تدعمه نسختك يظهر في الإعدادات ← «هذه النسخة المثبتة».

## كيف تحصل على إشارات
1. استورد بياناتك التاريخية الحقيقية (CSV) من شاشة التدريب.
2. أنشئ استراتيجية (أو حوّل القواعد التي اعتمدتها من كتبك وفيديوهاتك).
3. شغّل الاختبار التاريخي؛ إذا اجتاز البوابة (خارج العينة)، اعتمدها بنفسك.
4. ابدأ التحليل وارفع/التقط الشارت — BUY/SELL تظهر فقط عند تحقق شروطها وتوافق العوامل.
5. بعد كل صفقة تنفذها بنفسك سجّل نتيجتها من السجل (زر العلم بجانب الإشارة) — الإحصائيات والملاحظات تُبنى منها، منفصلة لكل نوع حساب.

## الخصوصية
كل البيانات على جهازك فقط. لا حسابات، لا سحابة، لا كلمات مرور منصات. النسخ الاحتياطية مشفرة (AES-256-GCM) بكلمة مرور لا تُحفظ. يمكنك حذف كل شيء من الإعدادات.

## تنبيه
التداول ينطوي على مخاطر عالية. الأداة مساعد تحليلي ولا تضمن أي ربح، ونسب الثقة المعروضة تقديرية ما لم تُوسم بأنها معايرة إحصائياً.
